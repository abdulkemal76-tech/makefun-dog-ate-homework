Entry for the make.fun bounty [The Dog Ate My Homework: Funniest Excuse](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

`main.py` (Python 3.13, standard library only) writes one line, under 200
characters, the excuse a dog gives after being caught eating the homework,
to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```
